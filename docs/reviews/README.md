# Reviews

这里保存方案评审和代码评审记录：

- 方案评审复制 [`../templates/design-review.md`](../templates/design-review.md)，使用 `YYYY-MM-DD-<slug>-design.md`。
- 代码评审复制 [`../templates/code-review.md`](../templates/code-review.md)，使用 `YYYY-MM-DD-<slug>-code.md`。

评审结论使用 `PASS`、`CONDITIONAL` 或 `BLOCK`。`BLOCK` 未解决前不能进入下一阶段。

方案评审属于编码前门禁；代码评审属于实现完成后的 `Review` 阶段。任务过程中的普通评论不会替代这两类正式评审。
