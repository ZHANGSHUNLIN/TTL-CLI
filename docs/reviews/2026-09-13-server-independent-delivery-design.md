## 评审门禁

- [x] Linux 服务端制品范围和客户端/服务端独立构建矩阵可接受。
- [x] `--listen`、`--port`、`--data-dir`、`/healthz` 和关闭契约覆盖运行周期，且
      不破坏现有 API 客户端。
- [x] 数据目录、权限、API Key、日志边界和外部 TLS 职责清晰。
- [x] 版本目录、升级前备份、健康探针和指针回滚适合目标环境。
- [x] 每条需求都有实现归属和测试/证据路径。
- [x] 容器、直连 TLS、高可用和 schema 迁移的后置决定没有留下无人负责的生产需求。
- [x] 生命周期包归属与 W-017 一致，不会增加第二个服务端入口。

## 已确认假设

1. Linux systemd（或等价管理器）作为首个参考部署目标。
2. `/healthz` 只表示进程和路由已就绪，不在每次探活中执行数据目录写入。
3. 公网 TLS 由反向代理或负载均衡器终止，`ttl-server` 本版本不直接管理证书。
4. 本版本不新增 bbolt 数据格式版本检查；若后续引入不兼容迁移，另立迁移任务。
