## Current Behavior

W-013 已纳入当前阶段承诺。本方案冻结并指导已实现的 v1 CLI 契约。

## Proposed Ownership

由 `internal/client/cli` 负责命令契约，复用 `internal/client/app.Service.ListResources` 和 `FindResources`；交互选择写 stderr，选中 value 写 stdout。

## Frozen Decisions

- v1 不承诺 `--print`；`--json` 和 `--non-interactive` 通过现有机器模式校验拒绝。
- 空数据库和无匹配均映射为 `not_found`，使用现有机器退出码 3。
- query 原样传给 `FindResources`，不裁剪首尾空格。
- 多匹配前检查 stdin/stderr 是否为交互终端；无 TTY 返回 `interaction_required`，不读取 stdin。
- `q`、Esc、Ctrl-C、EOF 返回 `cancelled`；空输入、非数字和越界返回 `invalid_choice`。
- `pick` 不记录命令 history 或 audit。

## Interfaces and Tests

`newPickCommand` 使用 `pick [query]` 和最多一个参数。单匹配直接输出 value；多匹配以稳定顺序编号并写 stderr，读取一次选择。成功输出规范化为最多一个尾随换行。单元测试覆盖流分离、选择/取消/非法输入、无 TTY 和只读行为；黑盒回归覆盖构建后二进制的管道和错误退出码。
