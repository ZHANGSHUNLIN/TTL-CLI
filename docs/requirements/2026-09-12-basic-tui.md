# Basic TUI Local Resource Loop

日期：2026-09-12
任务：W-007
状态：reviewed

## Problem And Goal

为本地资源提供 `ttl ui` 交互入口，复用既有 application service，不解析 CLI 文本，也不引入远端同步范围。

## Scope

### In Scope

- 浏览、搜索、详情、创建、修改、标签维护和安全删除。
- SQLite/bbolt、本地 TTY、空态/错误态/未保存编辑/窄屏布局。

### Out Of Scope

- cloud、sync、工作区管理、`ttl pick`、复制、打开和批量操作。

## Acceptance Criteria

- [x] CLI 与 TUI 共享 service 和存储生命周期。
- [x] 失败保存、删除确认、终端恢复和窄屏布局有实现或测试证据。
- [ ] 稳定 TUI 文案完成本地化。
- [ ] owner 完成真实终端完整流程和窄屏验收。
