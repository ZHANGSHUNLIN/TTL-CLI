# 需求分析：设计本地与云端数据同步及冲突处理

任务：W-020
类型：feature
状态：需求草案，已接收 W-019 边界输入

## 当前需求边界

W-020 负责 local 与 cloud 之间的数据同步、版本记录、增量传输和冲突处理，依赖 W-019
提供的两个稳定存储打开方式。一次同步操作只针对当前 workspace：不能在一次命令中跨多个
workspace 或向多个远程 profile 写入。远程 profile 可以配置多个，但当前应用或 workspace
只有一个活动项。

## 待确认内容

- 版本粒度、同步方向、增量协议和幂等规则。
- CRDT 类型、删除标记、不可自动合并冲突的人工处理流程。
- 同步失败重试、断网恢复和部分成功的可观察结果。
- 同步命令参数、状态输出和安全边界。

## 依赖与排除

- 依赖：[W-019 存储模式收敛](2026-09-13-W-019-storage-model-redesign.md)完成 local/cloud
  选择和 workspace/远程 profile 解析。
- 不改动 W-019 的 SQLite 存储格式，不把 sync 重新变成 storage 类型。
- 本文仍是需求草案，不代表同步协议、CRDT 或冲突规则已经确定。
